## 导入顺序

在上述同一张地图中，每个文件导入一个单独图层：

| 文件 | 图层 | 内容 |
| --- | --- | --- |
| transport.kml | 01 机场与跨城交通 | 上海出发、泰国境内换乘及 9/30 杭州返程 |
| phuket.kml | 02 普吉｜9/20—24 | 景点、餐厅、酒店与当地行程 |
| pattaya.kml | 03 芭提雅｜9/24—26 | 景点、餐厅、酒店与当地行程 |
| bangkok.kml | 04 曼谷｜9/26—30 | 景点、餐厅、酒店与当地行程 |

共 80 个地点（31 个机场/景点/交通/住宿区域/剧场、40 个餐饮地点、9 家候选酒店）。F1—F40、H1—H9 对应攻略编号；无固定地址的早餐、团餐等不标点。所有候选均未预订。

所有线只是地点顺序，不是实际驾车路线、航线或导航；BKK/DMK 依机票二选一。9/30 的返程终点为杭州萧山国际机场 HGH。

## 后续接入网页

1. 导入四个文件，确认地点和顺序示意线，按表格设置图层名称。
2. 设置地图可供朋友查看，并使用 Google 提供的“嵌入我的网站中”代码。
3. 说明 Google 图层需手动勾选，不能声称点击餐厅卡片会自动定位或按日期筛选 Google 地图。
4. 更改 canonical `_source`，执行既有检查和静态导出后，再发布到 GitHub Pages。

重新生成：在 `_source` 中先运行现有数据同步脚本，再运行 `node scripts/export-mymaps.mjs`。生成器读取原有坐标与引用，不会自动更新 Google 地图，需要重新导入对应图层。
