## 导入顺序

在上述同一张地图中，每个文件导入一个单独图层；不要为 A/B 新建第二张地图。

| 文件 | 图层 | 内容 |
| --- | --- | --- |
| transport.kml | 01 共同行程｜机场与跨城交通 | 4 个机场、9/20、9/24 和 9/26 跨城连线 |
| phuket.kml | 02 普吉｜9/20—24 | 共用景点、餐厅、酒店与当地行程 |
| pattaya.kml | 03 芭提雅｜9/24—26 | 共用景点、餐厅、酒店与当地行程 |
| bangkok.kml | 04 曼谷｜共用地点 | 共用景点、餐厅、酒店与 9/27—28 行程 |
| A.kml | 05 蓝线 A｜9/29 返程 | 9/29 退房→曼谷机场→上海 |
| B.kml | 06 红线 B｜9/29—10/1 | 专属地点、9/29—30 曼谷行程与 10/1 返程 |

共 79 个地点（30 个机场/景点/交通/住宿区域、40 个餐饮地点、9 家候选酒店）和 13 条顺序示意线。F1—F40、H1—H9 对应攻略编号；无固定地址的早餐、团餐等不标点。曼谷酒店的说明同时列出 A/B 入住日期。所有候选均未预订。

共用线为灰蓝色 #6c829b；A 蓝色 #1a6de3，B 红色 #e53935。A 返程线宽 7，B 线宽 3，以便路径重合时仍可分辨蓝色边缘；导入后需检查 Google 是否保留线色及线宽。也可单独勾选分支查看。所有线只是地点顺序，不是实际驾车路线、航线或导航；BKK/DMK 依机票二选一。

## 后续接入网页

1. 导入六个文件，确认 79 个点、13 条线及蓝红颜色，按表格设置图层名称。
2. 设置地图可供朋友查看，并使用 Google 提供的“嵌入我的网站中”代码。
3. 网页共用一张地图；A/B 按钮继续切换三餐、酒店日期和预算。说明 Google 图层需手动勾选，不能再声称点击餐厅卡片会自动定位或按日期筛选 Google 地图。
4. 更改 canonical `_source`，执行既有检查和静态导出后，再发布到 GitHub Pages。

重新生成：在 `_source` 中先运行现有数据同步脚本，再运行 `node scripts/export-mymaps.mjs`。生成器读取原有坐标与引用，不会自动更新 Google 地图，需要重新导入对应图层。
