02 / 一天怎么过

9/22 浮潜日参考节奏

  1. 07:00—09:00｜接送与装备轻早餐、确认海况，酒店接送至码头。试面镜、救生衣，告知三人均首次浮潜。
  2. 抵达后｜先适应，再下水在受保护、向导认可的区域练习面镜佩戴、呼吸管使用、排水和求助手势，能舒服呼吸再继续。
  3. 上午／午后｜分段体验与向导商定短时下水、中间上船休息。可按每次约 20—30 分钟考虑，感觉疲劳就提前结束，不追求凑满时长。
  4. 午饭后｜沙滩与返程天气和体力允许才进行第二次；按团方时间返回。晚上简单吃饭，不再安排跨岛活动。

时间为行程设计，不是已订团时刻表；不承诺点位、下水次数或能见度。

03 / 订团前问清楚

花钱买到真正的浮潜体验

  • 带队：向导是否全程下水？一位水中向导照顾几人？是否能照顾三位初次浮潜者？
  • 时间：几个下水点、实际水中时间多少？不是仅有“提供面镜，自行玩水”。
  • 装备：面镜、呼吸管、脚蹼、合身救生衣是否包含？近视面镜有无额外收费？
  • 总价：酒店往返接送、午餐、码头／上岛／公园费、保险是否包含？
  • 天气：停航怎样退款？改路线、取消浮潜但照常上岛时怎样处理？
  • 资质与救援：核实旅行社资质、船上救生设施、人员清点与应急联络方式。

“有导游”不一定等于“有水中向导”。上面列出的商家页面是询价参考，具体日期余位和服务安排仍需确认。

第一次下水，记住这六件事

  1. 先练习、再入海。优先用合适的传统面镜与独立呼吸管，先在水外试呼吸。
  2. 穿合身救生衣，三人保持可相互观察的距离，并始终跟随水中向导。
  3. 只做水面浮潜。不憋气比远、不自行下潜、不追鱼离队，不靠近船尾和螺旋桨。
  4. 不舒服就停止。面镜漏水、呛水、紧张、疲劳或呼吸异常时，立即示意向导协助返回。
  5. 不踩珊瑚、不喂鱼、不捡海洋生物。穿防晒泳衣，按当地要求使用防晒产品。
  6. 不在酒后或明显不适时下水。购买覆盖浮潜与紧急医疗救援的保险；团方保险不能代替自行核对保障。
